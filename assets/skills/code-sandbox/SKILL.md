# Code Sandbox

Run and test code snippets in isolated environments to verify logic, compute calculations, parse data, or generate charts.

## Guidelines

1. **Self-Contained Execution**:
   - Write clear, executable scripts with explicit dependencies, error handling, and output printing.
2. **Data & File Operations**:
   - Parse CSV, JSON, Markdown, and text data cleanly.
   - Summarize large outputs so critical findings are highlighted.
3. **Safety & Verification**:
   - Inspect command outputs and handle edge cases gracefully.
